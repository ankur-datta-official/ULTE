4. EXACT NO-TARGET MACHINE REASON

SOLE_SAME_SIDE_LEVEL_BROKEN: 150/150. Each of these 150 structure snapshots
contains exactly one direction-matching liquidity level (BUY_SIDE for UP,
SELL_SIDE for DOWN); that level's status is BROKEN at as-of. There is
no active same-side level to order or select. The extractor records every
level's side, status, price, confirmation time, swing ID, and exclusion result
and asserts that no eligible level was missed. Breakdown: 76 UP, 74 DOWN;
139 BREAKOUT_RETEST, 11 TREND_PULLBACK_CONTINUATION. Other machine reasons
(no level, wrong-side-only, future, at/behind entry, ordering mismatch) = 0.
This reflects the existing source's exclusion of resolved levels, including
the breakout reference consumed by the initiating break, plus the limited
structure window. A broken level is not a valid untraded target under the
current source contract. The diagnostic does not reclassify it as a target.

5. POST-ENTRY COUNTERFACTUAL — RESEARCH ONLY

For NO_STRUCTURAL_TARGET and NET_RR_BELOW_MINIMUM only, scan 15m OHLC from
the next bar until the existing invalidation price is touched. If target and
stop could both occur inside one bar, order is unknown: lower MFE uses only
the open on that stop bar, upper MFE includes its full favorable wick. MAE is
a lower bound to first stop. R divides by the existing entry-to-stop distance;
it is gross price excursion before execution costs. The calculation assumes
the reference entry is attainable at the next open, and does not model fills,
latency, a tradable target, or an actual strategy return.

7. TARGET FINDER CORRECTNESS AND DISPOSITION

The source audit checked long/short side symmetry; strict profit-side price;
nearest ordering with stable equal-price source order; confirmed-at and
window-end fences; same setup timeframe; stale/BROKEN/SWEPT exclusion;
duplicate level order; first eligible target precedence; exact decimal
arithmetic; and stop/cost symmetry. The existing shared risk/structure tests
exercise those conditions. Every recorded risk result matches a fresh call
to the same shared engine; an independent level-exclusion pass found no
eligible level in the 150 no-target cases. No target finder correctness
defect was found, so production code and trading semantics were not changed.

PRIMARY_FUNNEL_BOTTLENECK = TARGET_DISCOVERY_CORRECT_BUT_TOO_SPARSE.
The 150/205 no-target gate dominates, and 129/150 no-target cases have <3R
